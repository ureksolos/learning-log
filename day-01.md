## What I understand now.

- A file extension tells the computer what kind of file it is and what program should open the file.
- Python checks the .py file for errors. If correct, Python compiles the text, then performs/executes the actions that have been written.
- Git is a content tracker. It keeps track of changes in a file over time. It does not matter what language used, file extension, or even the correctness of the content. it tracks the bytes in a file and snapshot them whenever one commits, without any opinion about what they mean or do. For example, Python has to understand main.py to run the file, but Git does not need to understand it to save it, it is very possible to commit a file full of gibberish or a file Git has never seen the contents of before. Git just needs to track every change to it.
